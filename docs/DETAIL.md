# CoserWiki 漫展提醒

把 [coserwiki](https://coserwiki.com/events)（Coser百科）的漫展活动接进 DSH。

## 能做什么

- 在 DSH 里浏览全部漫展活动，按城市筛选、按关键词搜索，点卡片直接打开 coserwiki 活动页。
- 关注任意 coser：有他们参演的活动会标「关注」，并列出嘉宾名字和参演日期。
- 点卡片下方的「参演名单」，直接展开这一场的嘉宾名单（关注的嘉宾高亮）。
- 到你设置的时间点弹提醒（默认开始前 **1 个月** 和 **1 周**），写明哪位嘉宾、哪天参演。
- 提醒是右下角轻提示：最多同时 3 条，可「稍后提醒」（30 分钟后再来）或「查看活动」；超过 3 条收进「还有 N 条提醒」。
- 关掉 DSH 期间错过的提醒，下次打开会补弹。
- 标题栏「日历」把关注嘉宾的场次导出成 `.ics`，可直接导入系统日历。

## 在哪看

- 左侧栏「漫展活动」图标。
- 对话区顶部「漫展活动」标签。
- 右侧栏「漫展活动」Tab（有新活动时会自动打开）。

## 修改关注名单和提醒时间

打开 **设置 → 插件 → 漫展提醒**（不同 DSH 版本入口略有差异）：

- **关注嘉宾**：输入 coser 名字，点「添加」；点标签上的 `×` 移除。
- **提醒时间**：点「1 个月 / 2 周 / 1 周 / 3 天 / 1 天 / 当天」多选，或在下面填自定义天数（0–365）点「添加」，最多 6 个节点。下面会实时显示「当前：活动开始前 … 各提醒一次」。
- 最后点「保存设置」，立即生效。

默认名单：egg258、腥味猫罐、兔娘、害羞7、听霜。默认提醒：提前 30 天、7 天。

## 数据与隐私

- 只读取公开活动页 <https://coserwiki.com/events>，不登录、不上传任何账号信息。
- 优先解析页面内嵌的结构化数据（活动名、起止日期、省市、场馆、参演名单），HTML 卡片只做兜底。
- 关注名单和上次抓取状态保存在本机 `~/.dsh/coserwiki-reminder/`。
- 每 30 分钟抓一次；抓取失败 5 分钟后自动重试，面板上也有手动刷新。

## 已知限制

- 只在 DSH 运行时检查提醒，DSH 关闭期间不会弹系统通知。
- 活动数据来自 coserwiki 页面；对方改版可能导致抓取暂时失效，面板会显示错误原因和一键重试。
- 关注嘉宾按名字精确匹配（忽略大小写、全角半角和空格）；如果 coserwiki 上的名字和输入不一致，需要在设置里改成页面上的写法。
- 单场名单最多保存 120 位嘉宾，超出部分在面板里显示为「等 N 人」。
