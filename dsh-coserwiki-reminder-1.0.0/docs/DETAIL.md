# CoserWiki 漫展提醒

把 [coserwiki](https://coserwiki.com/events)（Coser百科）的漫展活动接进 DSH。

## 能做什么

- 在 DSH 里浏览全部漫展活动，按城市筛选，点卡片直接打开 coserwiki 活动页。
- 关注任意 coser：有他们参演的活动会标「关注」，并列出嘉宾名字和参演日期。
- 活动开始前 **1 个月** 和 **1 周** 各弹一次提醒；弹窗里写明哪位嘉宾、哪天参演。
- 关掉 DSH 期间错过的提醒，下次打开会补弹。

## 在哪看

- 左侧栏「漫展活动」图标。
- 对话区顶部「漫展活动」标签。
- 右侧栏「漫展活动」Tab（有新活动时会自动打开）。

## 修改关注名单

打开 **设置 → 插件 → 漫展提醒**（不同 DSH 版本入口略有差异），在输入框里输入 coser 名字，点「添加」，再点「保存关注名单」立即生效。

默认名单：egg258、腥味猫罐、兔娘、害羞7、听霜。

## 数据与隐私

- 只读取公开活动页 <https://coserwiki.com/events>，不登录、不上传任何账号信息。
- 关注名单和上次抓取状态保存在本机 `~/.dsh/coserwiki-reminder/`。
- 每 30 分钟抓一次；面板上也有手动刷新。

## 已知限制

- 只在 DSH 运行时检查提醒，DSH 关闭期间不会弹系统通知。
- 活动数据来自 coserwiki 页面；对方改版可能导致抓取暂时失效，面板会显示错误原因。
- 关注嘉宾按名字精确匹配；如果 coserwiki 上的名字和输入不一致，需要在设置里改成页面上的写法。
